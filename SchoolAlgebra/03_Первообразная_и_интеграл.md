## §7. Первообразная

### 26. Определение первообразной

Интегрирование — операция, обратная дифференцированию: по заданной
производной находят саму функцию.

> **Определение.** Функция $F$ называется *первообразной* для функции $f$ на
> заданном промежутке, если для всех $x$ из этого промежутка
> $$F'(x)=f(x).$$

**Примеры.**
- $F(x)=\dfrac{x^3}{3}$ — первообразная для $f(x)=x^2$ на $\mathbb R$
  (так как $F'(x)=x^2$);
- $F(x)=2\sqrt{x}$ — первообразная для $f(x)=\dfrac{1}{\sqrt{x}}$ на $(0;\infty)$;
- $F(x)=-\dfrac1x$ — первообразная для $f(x)=\dfrac{1}{x^2}$ (на каждом из
  промежутков $(-\infty;0)$ и $(0;\infty)$).

Задача нахождения первообразной имеет бесконечно много решений: вместе с $F$
первообразной является и $F+C$ при любой постоянной $C$.

---

### 27. Основное свойство первообразной

> **Признак постоянства функции.** Если $F'(x)=0$ на промежутке $I$, то $F$
> постоянна на этом промежутке.

> **Теорема (основное свойство первообразных).** Любая первообразная для
> функции $f$ на промежутке $I$ может быть записана в виде
> $$F(x)+C,$$
> где $F$ — одна из первообразных для $f$ на $I$, а $C$ — произвольная
> постоянная.

**Геометрический смысл.** Графики любых двух первообразных получаются друг из
друга параллельным переносом вдоль оси $Oy$.

Совокупность всех первообразных называют **неопределённым интегралом** и
записывают

$$\int f(x)\,dx = F(x)+C.$$

**Таблица первообразных:**

| $f(x)$ | Общий вид первообразных $\int f(x)\,dx$ |
|---|---|
| $k$ (постоянная) | $kx+C$ |
| $x^n$ ($n\in\mathbb Z$, $n\ne -1$) | $\dfrac{x^{n+1}}{n+1}+C$ |
| $\dfrac{1}{x^2}$ | $-\dfrac1x+C$ |
| $\sin x$ | $-\cos x+C$ |
| $\cos x$ | $\sin x+C$ |
| $\dfrac{1}{\cos^2 x}$ | $\tan x+C$ |
| $\dfrac{1}{\sqrt x}$ | $2\sqrt x+C$ |

**Пример.** Общий вид первообразных для $f(x)=-x^3$:
$F(x)=-\dfrac{x^4}{4}+C$.

**Пример.** Для $f(x)=\dfrac1{x^2}$ первообразная, принимающая при $x=1$
значение $1$: $F(x)=-\dfrac1x+C$, $F(1)=-1+C=1\Rightarrow C=2$, значит
$F(x)=-\dfrac1x+2$.

**Пример (механика).** Точка движется с постоянным ускорением $a$; при $t=0$
координата $x_0$, скорость $v_0$. Поскольку $v'(t)=a$, $x'(t)=v(t)$,
получаем $v(t)=at+v_0$ и

$$x(t)=\frac{at^2}{2}+v_0 t+x_0.$$

---

### 28. Три правила нахождения первообразных

> **Правило 1.** Если $F$ — первообразная для $f$, а $G$ — для $g$, то
> $F+G$ — первообразная для $f+g$.

> **Правило 2.** Если $F$ — первообразная для $f$, а $k$ — постоянная, то
> $kF$ — первообразная для $kf$.

> **Правило 3.** Если $F(x)$ — первообразная для $f(x)$, а $k$ и $b$ —
> постоянные, $k\ne 0$, то $\dfrac1k F(kx+b)$ — первообразная для
> $f(kx+b)$.

**Пример.** Для $f(x)=x^3-\dfrac1{x^2}$ одна из первообразных —
$\dfrac{x^4}{4}+\dfrac1x$.

**Пример.** Для $f(x)=5\cos x$: $F(x)=5\sin x$.

**Пример.** Для $f(x)=\sin(3x-2)$: поскольку первообразная для $\sin x$ есть
$-\cos x$,
$$F(x)=-\frac13\cos(3x-2).$$

**Пример (механика).** Тело массой $m$ движется по оси $Ox$ под действием силы
$F(t)=3-2t$; при $t=2$ с скорость $v=3$ м/с, координата $x=1$ м. Из
$F=ma$ находим $a(t)=\dfrac{3-2t}{m}$; последовательным интегрированием
получают $v(t)$, затем $x(t)$, определяя постоянные из начальных условий.

## §8. Интеграл

### 29. Площадь криволинейной трапеции

Пусть на отрезке $[a;b]$ оси $Ox$ задана непрерывная функция $f$, не меняющая
знак. Фигуру, ограниченную графиком $f$, отрезком $[a;b]$ и прямыми $x=a$,
$x=b$, называют **криволинейной трапецией**.

> **Теорема.** Если $f$ — непрерывная и неотрицательная на $[a;b]$ функция, а
> $F$ — её первообразная на этом отрезке, то площадь криволинейной трапеции
> равна приращению первообразной:
> $$\boxed{S=F(b)-F(a)}.$$

(Доказательство: функция площади $S(x)$ удовлетворяет $S'(x)=f(x)$, т.е.
является первообразной; из $S(a)=0$ следует $S(x)=F(x)-F(a)$, а при $x=b$
получаем искомое.)

**Пример.** Площадь фигуры под графиком $f(x)=x^2$, ограниченной прямыми
$y=0$, $x=1$, $x=2$:
$$S=F(2)-F(1)=\frac{2^3}{3}-\frac{1^3}{3}=\frac73.$$

> **Замечание.** Любая непрерывная на промежутке функция имеет на нём
> первообразную. Однако первообразные некоторых функций нельзя выразить через
> элементарные функции (например, $\sqrt{x^3+1}$).

### 30. Интеграл. Формула Ньютона — Лейбница

Разобьём $[a;b]$ на $n$ равных отрезков точками
$a=x_0<x_1<\dots<x_n=b$, $\Delta x=\dfrac{b-a}{n}$. Сумма
$$S_n=\big(f(x_0)+f(x_1)+\dots+f(x_{n-1})\big)\Delta x$$
при $n\to\infty$ стремится к числу, которое называют **интегралом** функции
$f$ от $a$ до $b$:

$$\int_a^b f(x)\,dx.$$

Числа $a$ и $b$ — пределы интегрирования (нижний и верхний), $f$ —
подынтегральная функция, $x$ — переменная интегрирования.

Если $f(x)\ge 0$ на $[a;b]$, то площадь криволинейной трапеции

$$S=\int_a^b f(x)\,dx.$$

> **Формула Ньютона — Лейбница.** Если $F$ — первообразная для $f$ на $[a;b]$
> (при $f$ непрерывной на $[a;b]$), то
> $$\boxed{\int_a^b f(x)\,dx = F(b)-F(a) = F(x)\Big|_a^b}.$$

**Пример.** $\displaystyle\int_{-1}^{2} x^2\,dx = \frac{x^3}{3}\Big|_{-1}^{2}
= \frac{8}{3}-\frac{-1}{3}=3.$

**Пример.** $\displaystyle\int_0^\pi \sin x\,dx = -\cos x\Big|_0^\pi = -\cos\pi+\cos 0 = 2.$

**Пример.** Площадь фигуры, ограниченной линиями $y=1-x$ и
$y=3-2x-x^2$. Точки пересечения: $x=1$ и $x=-2$ (из $1-x=3-2x-x^2$).
Искомую площадь можно найти как разность площади криволинейной трапеции под
параболой и площади треугольника; в итоге
$$S=\int_{-2}^{1}\big[(3-2x-x^2)-(1-x)\big]dx
=\int_{-2}^{1}(2-x-x^2)\,dx=4{,}5.$$

> **Замечание.** По определению полагают при $a\ge b$:
> $\displaystyle\int_a^b f\,dx=-\int_b^a f\,dx$, в частности
> $\displaystyle\int_a^a f\,dx=0$; при этом формула Ньютона — Лейбница верна
> при любых $a,b$.

### 31. Применения интеграла

#### Объём тела

Если для тела известна площадь $S(x)$ его сечения плоскостью, перпендикулярной
оси $Ox$ и проходящей через точку $x\in[a;b]$, причём $S$ непрерывна, то

$$\boxed{V=\int_a^b S(x)\,dx}.$$

**Объём тела вращения.** При вращении криволинейной трапеции (график
$f\ge 0$ на $[a;b]$) вокруг оси $Ox$ сечение — круг радиуса $f(x)$,
$S(x)=\pi f^2(x)$, и

$$\boxed{V=\int_a^b \pi f^2(x)\,dx}.$$

**Пример.** Объём усечённой пирамиды высотой $H$ с площадями оснований $S$ и
$s$: $V=\dfrac{H}{3}\big(S+s+\sqrt{Ss}\big)$.

#### Работа переменной силы

Если точка движется по оси $Ox$ под действием силы, проекция которой
$f(x)$ (непрерывная функция) на отрезке $[a;b]$, то работа

$$\boxed{A=\int_a^b f(x)\,dx}.$$

**Пример.** Сила упругости растянутой на 5 см пружины равна 3 Н. По закону
Гука $F=kx$, откуда $3=k\cdot0{,}05$, $k=60$, $F=60x$. Работа растяжения:

$$A=\int_0^{0{,}05} 60x\,dx = 30x^2\Big|_0^{0{,}05}=0{,}075\ \text{Дж}.$$

#### Центр масс

Координата центра масс системы материальных точек:
$$x' = \frac{m_1x_1+m_2x_2+\dots+m_nx_n}{m_1+m_2+\dots+m_n}.$$

Для стержня $[a;b]$ с непрерывной плотностью $\rho(x)$:
$$M=\int_a^b \rho(x)\,dx,\qquad x'=\frac1M\int_a^b x\,\rho(x)\,dx.$$

## Сведения из истории (кратко)

- Задачи на **квадратуры** (вычисление площадей) и **кубатуры** (объёмов)
  решались ещё в античности методом исчерпывания (**Евдокс**, затем
  **Архимед**), который по существу предвосхитил идеи интегрального
  исчисления.
- Метод **неделимых** (Кеплер, Кавальери, Торричелли, XVII в.) позволил
  вычислить ряд площадей и объёмов; **принцип Кавальери**: если прямые
  параллельного пучка пересекают две фигуры по отрезкам равной длины, их
  площади равны.
- **П. Ферма** (1629) вывел $\displaystyle\int x^n\,dx=\frac{x^{n+1}}{n+1}+C$.
- Знак интеграла $\int$ ввёл **Лейбниц** (1675); термин «интеграл» —
  **Я. Бернулли** (1690); название «интегральное исчисление» — 1696 г.
- Формула **Ньютона — Лейбница** окончательно связала дифференцирование и
  интегрирование.
- **Л. Эйлер** завершил систематическое интегрирование элементарных функций;
  **П. Л. Чебышев** доказал существование интегралов, не выразимых через
  элементарные функции.
- Строгая теория интеграла — **О. Коши**, **Б. Риман**, **Г. Дарбу** (XIX в.);
  обобщения — **А. Лебег**, **А. Данжуа**, **А. Я. Хинчин** (XX в.).
