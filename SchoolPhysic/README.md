# SchoolPhysic

Конспект школьного курса физики по пособию И. В. Яковлева (MathUs.ru).
Определения переформулированы (EN + RU), формулы соответствуют источнику,
к каждому закону указан автор и его труд. Формулы и законы природы не
охраняются авторским правом; текст изложен своими словами, графики извлечены
из пособия в ознакомительных целях.
